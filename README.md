# 🛍️ Minimall — Современный E-Commerce Маркетплейс

**Minimall** — это высокопроизводительное, стильное и адаптивное веб-приложение интернет-магазина, построенное на стеке **React 19**, **TypeScript**, **Vite** и **Tailwind CSS v4**. 

Проект сочетает в себе премиальный внешний вид (с поддержкой переключения светлой/тёмной темы, плавными микро-анимациями и эффектом Glassmorphism) и продвинутую функциональность администрирования каталога и заказов.

---

## ✨ Ключевые Возможности

### 🛒 Для Покупателей
* **🎨 Динамическая смена темы**: Переключатель Light / Dark режим с плавным переходом и полной адаптацией всех UI-элементов.
* **🔍 Умный Каталог & Фильтрация**: Удобный поиск по названиям, фильтрация по категориям, цене и бренд-параметрам.
* **💖 Избранное (Wishlist)**: Сохранение понравившихся товаров с автоматической синхронизацией в `localStorage`.
* **🛍️ Корзина и Оформление**: Удобный выпадающий drawer корзины, подсчет стоимости со скидками и модальное окно быстрого оформления заказа.
* **📱 Адаптивный Дизайн**: Полная поддержка мобильных устройств, планшетов и десктопов.
* **🖼️ Карусель Новостей и Акций**: Интерактивные промо-баннеры с рекомендациями по размерам изображений.

### 🛠️ Панель Администратора
* **📦 Управление Товарами**: Добавление и редактирование товаров с поддержкой нескольких URL-картинок или загрузкой файлов.
* **📐 Подсказки по Размерам**: Автоматические рекомендации идеальных пропорций изображений для карточек товаров и баннеров.
* **📋 Управление Заказами**: Просмотр поступающих заказов от клиентов в реальном времени, изменение статусов обработки.
* **📰 Управление Новостной Каруселью**: Гибкая настройка промо-слайдов на главной странице.

## ⚡ Оптимизация и Производительность

Проект прошёл полный технический аудит производительности:
* **Мемоизация компонентов**: Использование `React.memo` для карточек товаров (`ProductCard`), устраняющее лишние перерендеры при изменении корзины или темы.
* **Оптимизация вычислений**: Использование `useMemo` и `useCallback` для расчёта итогов корзины и обработки событий.
* **Кэширование форматирования цен**: Создана общая утилита `formatPrice` с закэшированным экземпляром `Intl.NumberFormat`.
* **Debounced State Persistence**: Сохранение изменений каталога в `localStorage` выполняется с дебаунсом (400 мс), предотвращая фризы UI при частом вводе.
* **Оптимизированные CSS-анимации**: Правильно настроенные свойства `transition` без нагрузки на графический процессор.

## 🚀 Быстрый Запуск

### Предварительные требования
* **Node.js**: v18.0.0 или выше
* **pnpm** / **npm** / **yarn**

### Инструкция по установке

1. **Клонируйте репозиторий**:
   ```bash
   git clone https.://github.com/YusufS7-CR7/Minimall.git
   cd Minimall
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите сервер для разработки**:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу: `http://localhost:5173`

4. **Сборка для Production**:
   ```bash
   npm run build
   ```

5. **Предпросмотр Production-сборки**:
   ```bash
   npm run preview
   ```

├── package.json            # Зависимости и скрипты
